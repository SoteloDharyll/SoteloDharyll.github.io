# Dharyll Sotelo Portfolio

Static portfolio website prepared for GitHub Pages.

## Upload to GitHub Pages

Upload the CONTENTS of this folder to the root of the repository:
SoteloDharyll/SoteloDharyll.github.io

Required root files:
- index.html
- styles.css
- resources/profile-picture.png
- resources/velora-photo.png
- resources/xauusd-research-photo.png

Do not upload the ZIP itself to GitHub Pages. Extract it first, then upload the files/folder inside.
